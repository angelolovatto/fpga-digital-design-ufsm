# FPGA & Digital Design Projects — UFSM

Portfolio overview of academic work developed in **Digital Design with FPGA** during the Computer Engineering program at the **Federal University of Santa Maria (UFSM)**.

The projects explored combinational and sequential logic, finite-state machines, timing, display multiplexing, testbenches, and FPGA-oriented implementation using VHDL.

## Selected projects

### Traffic Light Controller
Finite-state-machine based controller with timed state transitions, pedestrian requests, and additional operating modes.

### Seven-State FSM
Design and simulation of a synthesizable seven-state finite-state machine with a dedicated testbench.

### FUMIGA / MIÓCA
Academic digital systems involving state-based control, timing, and multiplexed seven-segment display output.

### 5-input / 3-output Combinational Circuit
Combinational-logic implementation and verification covering the complete input truth table.

## Technologies and concepts

`VHDL` · `FPGA` · `FSM` · `Testbench` · `Xilinx ISE/ISim` · `Spartan-6` · `Nexys 3` · `Combinational Logic` · `Sequential Logic`
